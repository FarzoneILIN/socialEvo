# Relation Taxonomy

关系标签以“主体对 × 任务对象 × 时间窗口”为单位，并区分环境提供的潜在外部性与轨迹中观察到的实现关系。

| Label | Operational criterion |
| --- | --- |
| `cooperation` | 共享投入、互补执行或联合承诺对对方或联合产出产生正向可比较贡献 |
| `competition` | 争取排他收益/控制权，并存在可比较的排挤或收益冲突 |
| `irrelevant` | 干预后对方效用和策略变化落入预注册的实用等效区间 |
| `mixed` | 在不同对象、阶段或资源上同时出现合作与竞争 |
| `undetermined` | 现有轨迹和干预不足以判定 |

通信频率、聊天措辞和自我声明作为解释字段，不作为关系金标准。关系判据由 E0 原子关系实验校准，再应用到 E1-E4 复杂任务。关系事件、机会数、持续时间、切换和识别误差均需记录。
