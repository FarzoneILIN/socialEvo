# Future implementation boundary

本目录只记录未来实现的模块边界，当前不包含实验实现。

- `envs/`：状态转移、行动、资源和 verifier。
- `agents/`：模型/provider adapter、上下文、工具调用。
- `protocols/`：固定协议、自组织动作和组织状态。
- `runners/`：episode、continuation、预算和回放。
- `relations/`：外部性、关系事件和未判定标签。
- `interventions/`：快照、分叉和功能干预。
- `recommenders/`：事前任务特征和候选协议选择。
- `evaluation/`：效用、统计、bootstrap 和结果汇总。
- `tracking/`：manifest、schema、provenance 和成本日志。
